# Restaurant Design

The home page of a responsive website for a fictional Chinese restaurant called "China Bistro". I built it in **June 2016** while following the lectures of the **HTML, CSS, and Javascript for Web Developers** course on **Coursera**, which Johns Hopkins University teaches. It's one of my first web development projects. I've kept it here as a record of where I started, so it shows the code as it was then. It isn't maintained, and only the home page was built.

## What it does

- Shows a restaurant home page with a logo, a navigation bar, a large banner image and three tiles that link to the menu, the specials and a map.
- Adjusts the layout for phone, tablet and desktop screens using the Bootstrap grid.
- Folds the navigation into a "hamburger" menu on small screens.
- Loads a different size of banner and logo image depending on the screen width.
- Includes an embedded Google Map and a phone number that can be tapped to call.

## Technologies used

- **HTML5**
- **CSS3**, including custom styles and media queries
- **Bootstrap 3** for the grid, the navbar, the collapsing menu and Glyphicons icons
- **jQuery**, which Bootstrap's JavaScript needs
- **Google Fonts** (Oxygen) and an embedded **Google Maps** iframe
- **Git** and **GitHub**

## What I learned

- How to plan a mobile-first page that works on phones, tablets and desktops.
- How to use the Bootstrap grid, with classes like `col-xs`, `col-sm` and `col-md`, to build responsive layouts.
- How to use Bootstrap components such as the navbar, the collapsing menu, the jumbotron and the icons.
- How to change Bootstrap's look with my own CSS and media queries.
- How to load responsive images for different screen sizes.
- How to embed content from other sites, such as Google Maps and Google Fonts.
- How to turn a design into a working web page by following a structured university course.
